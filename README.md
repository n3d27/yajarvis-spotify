# Spotify для YaJarvis

Плагин `spotify` для [YaJarvis](https://github.com/newfpv/YaJarvis) — голосового помощника на колонках Яндекса с рутом. Он делает Spotify первым источником музыки и управляет им через Soloist, который работает прямо на колонке.

Репозиторий: https://github.com/n3d27/yajarvis-spotify

## Что умеет

- Spotify становится первым источником музыки для Джарвиса. Плагин добавляет два инструмента:
  - `spotify_play` — включить трек, исполнителя, альбом, плейлист или подкаст;
  - `spotify_control` — пауза, продолжить, дальше, назад, лайк, дизлайк, перемешать или по порядку, статус.
- «Моё любимое» играет по порядку, «любимое вперемешку» — в случайном порядке, «рекомендации» включают подборку на основе ваших любимых треков.
- Лайк и дизлайк текущего трека.
- Пауза, дальше, назад. «Назад» всегда включает предыдущий трек, а не перематывает текущий к началу.
- Быстрые фразы работают сразу, без раздумий модели: «лайк», «дизлайк», «моё любимое», «любимое вперемешку», «рекомендации».
- Пока Джарвис говорит, Spotify ставится на паузу, а после разговора продолжает играть. Это нужно, потому что Soloist и голос Джарвиса не могут одновременно занимать звуковое устройство колонки: без паузы ответ не слышно. Музыку возобновляет только плагин, и только если паузу поставил он сам: если вы нажали паузу вручную, она так и останется.
- Если попросить включить музыку прямо во время разговора, она начнётся после ответа Джарвиса, а не поверх его голоса.

## Что нужно заранее

- Колонка Яндекс с рутом и YaJarvis 0.10.16 или новее.
- Spotify на колонке через Soloist (пакет `soloist-station-lite`). Проверка: в приложении Spotify на телефоне колонка видна в списке устройств и играет.
- Spotify Premium — без него Soloist не работает.

## Установка

**1. Поставьте плагин.** В панели Джарвиса: **Подключения → Плагины → От сообщества → Spotify → Установить.**

**2. Ключи Spotify.** Выберите свой случай:

- **Soloist уже умеет искать музыку голосом** (в `/data/opt/soloist/spotify_api.conf` есть ключи) — ничего вводить не нужно, плагин возьмёт ключи оттуда. Переходите к шагу 3.
- **Иначе** — заведите ключи за пару минут:
  1. Откройте https://developer.spotify.com/dashboard и войдите своим аккаунтом Spotify.
  2. **Create app** → любое название и описание → в **Redirect URI** впишите `http://127.0.0.1:8888/callback` → сохраните.
  3. Откройте **Settings** приложения, скопируйте **Client ID** и **Client Secret**.
  4. В панели Джарвиса откройте настройки плагина Spotify, вставьте оба значения и нажмите **Сохранить**.

  Этого хватит, чтобы Джарвис включал музыку и управлял ей. Для лайков и «моего любимого» нужен ещё **refresh token** — см. ниже.

**3. Подскажите Джарвису, что музыка — в Spotify.** В панели откройте свой профиль ассистента и добавьте в его промпт строку:

> Музыку сначала включай через Spotify (spotify_play), а управляй ей через spotify_control. YouTube (play_music) — только если в Spotify не нашлось или просят видео.

Без этой строки модель иногда выбирает встроенный YouTube.

Готово — скажите «Джарвис, включи Кино».

<details>
<summary>Как получить refresh token (для лайков и «моего любимого»)</summary>

1. Откройте в браузере адрес, подставив свой Client ID:

   ```
   https://accounts.spotify.com/authorize?client_id=ВАШ_CLIENT_ID&response_type=code&redirect_uri=http%3A%2F%2F127.0.0.1%3A8888%2Fcallback&scope=user-library-read%20user-library-modify%20user-read-private
   ```

2. Нажмите «Принять». Браузер перейдёт на `http://127.0.0.1:8888/callback?code=…` — страница не откроется, это нормально. Скопируйте всё, что после `code=`.
3. В терминале на компьютере выполните, подставив свои значения:

   ```
   curl -s -u ВАШ_CLIENT_ID:ВАШ_CLIENT_SECRET \
     -d grant_type=authorization_code \
     -d code=СКОПИРОВАННЫЙ_КОД \
     -d redirect_uri=http://127.0.0.1:8888/callback \
     https://accounts.spotify.com/api/token
   ```

4. В ответе найдите `"refresh_token": "…"` и вставьте значение в поле **Refresh token** в настройках плагина.

</details>

<details>
<summary>Что означают остальные поля настроек</summary>

- **Адрес «Любимых треков»** — оставьте пустым, плагин найдёт сам.
- **Папка Soloist на колонке** — менять не нужно, если Soloist ставился пакетом `soloist-station-lite`.
- **Ставить музыку на паузу, пока Джарвис говорит** — лучше не выключать: пока играет Spotify, голос Джарвиса не слышно.

</details>

<details>
<summary>Установка без каталога</summary>

Скачайте `jarvis-plugin-arm64.zip` из раздела [Releases](https://github.com/n3d27/yajarvis-spotify/releases/latest) и в панели выберите **Подключения → Плагины → Плагин из файла**.

</details>

## Известные ограничения

- Пауза на время разговора опирается на строки журнала YaJarvis. Если обновление ядра изменит их текст, плагин не увидит конец разговора; тогда через 3 минуты сработает страховка и музыка продолжится сама.
- Карточки плеера в панели нет: плагин не может рисовать свой интерфейс.
- Только arm64.
- В некоторых версиях YaJarvis фразы про музыку уходят Алисе, когда включён канал умного дома «Алиса». Если у вас установлен мост Алисы со Spotify, это может запустить второй, другой трек. Обходной путь: выключить этот канал или не обращать внимания.
- Строка статуса в карточке плагина не показывается. Спросите голосом «что играет в Spotify».

## Сборка из исходников

```sh
cargo test
scripts/release.sh
```

Для `scripts/release.sh` нужен rustup с целью `aarch64-unknown-linux-musl` и zig (для C-зависимостей). Скрипт соберёт `dist/jarvis-plugin-arm64.zip`.
