# Spotify для YaJarvis

Плагин `spotify` для [YaJarvis](https://github.com/newfpv/YaJarvis) — голосового помощника на колонках Яндекса с рутом. Он делает Spotify первым источником музыки и управляет им через Soloist, который работает прямо на колонке.

Репозиторий: https://github.com/n3d27/yajarvis-spotify

## Что умеет

- Spotify становится первым источником музыки для Джарвиса. Плагин добавляет два инструмента:
  - `spotify_play` — включить трек, исполнителя, альбом, плейлист или подкаст;
  - `spotify_control` — пауза, продолжить, дальше, назад, лайк, дизлайк, перемешать или по порядку, статус.
- «Моё любимое» играет по порядку, «любимое вперемешку» — в случайном порядке, «рекомендации» включают подборку на основе ваших любимых треков.
- Лайк и дизлайк текущего трека.
- Пауза, дальше, назад. «Назад» всегда включает предыдущий трек, а не перематывает текущий к началу.
- Быстрые фразы работают сразу, без раздумий модели: «лайк», «дизлайк», «моё любимое», «любимое вперемешку», «рекомендации».
- Пока Джарвис говорит, Spotify ставится на паузу, а после разговора продолжает играть. Это нужно, потому что Soloist и голос Джарвиса не могут одновременно занимать звуковое устройство колонки: без паузы ответ не слышно. Музыку возобновляет только плагин, и только если паузу поставил он сам: если вы нажали паузу вручную, она так и останется.
- Если попросить включить музыку прямо во время разговора, она начнётся после ответа Джарвиса, а не поверх его голоса.

## Что нужно

- YaJarvis версии 0.10.16 или новее на колонке с процессором arm64.
- Soloist, установленный пакетом `soloist-station-lite` в `/data/opt/soloist`, со скриптом `scripts/control.sh`.
- Аккаунт Spotify Premium: без него Soloist не работает.
- Приложение разработчика Spotify (Client ID и Client Secret):
  1. Откройте https://developer.spotify.com/dashboard и войдите в свой аккаунт.
  2. Нажмите Create app, придумайте название и описание.
  3. В поле Redirect URI укажите `http://127.0.0.1:8888/callback`.
  4. После создания откройте Settings приложения и скопируйте Client ID и Client Secret.
- Refresh token — нужен для лайков и «моего любимого». Если поля в настройках плагина пустые, плагин сам читает файл `/data/opt/soloist/spotify_api.conf`. Поэтому тем, у кого стоит `soloist-station-lite`, ничего дополнительно вводить не нужно.

  Если токена нет, получите его обычным способом Spotify — authorization code flow:
  1. Откройте в браузере страницу авторизации Spotify (`https://accounts.spotify.com/authorize`) со своим `client_id`, `response_type=code`, `redirect_uri=http://127.0.0.1:8888/callback` и `scope=user-library-read user-library-modify user-read-private`.
  2. Разрешите доступ. Браузер перейдёт на адрес вида `http://127.0.0.1:8888/callback?code=...` (страница не откроется, это нормально), скопируйте значение `code`.
  3. Обменяйте код на токены запросом `POST https://accounts.spotify.com/api/token` с параметрами `grant_type=authorization_code`, `code`, `redirect_uri`, авторизуясь Client ID и Client Secret (HTTP Basic).
  4. В ответе возьмите `refresh_token` и вставьте его в настройки плагина.

## Установка

1. Откройте панель YaJarvis: Подключения → Плагины → От сообщества, найдите Spotify и установите. Либо скачайте `jarvis-plugin-arm64.zip` из раздела Releases этого репозитория и выберите «Плагин из файла».
2. Откройте настройки плагина и заполните поля:
   - **Spotify client_id** и **Spotify client_secret** — ключи вашего приложения разработчика;
   - **Spotify refresh_token** — токен пользователя для лайков и «любимого»; можно оставить пустым, если ключи лежат в `spotify_api.conf` Soloist;
   - **URI любимых (необязательно)** — адрес коллекции «Любимые треки»; если пусто, плагин вычислит его сам;
   - **Каталог Soloist** — где установлен Soloist, по умолчанию `/data/opt/soloist`;
   - **Пауза на время разговора** — включено по умолчанию; выключите, если пауза не нужна.

## Строка для промпта профиля

Встроенный инструмент YaJarvis `play_music` (YouTube) тоже претендует на запросы про музыку, и модель может выбрать его вместо Spotify. Добавьте в промпт профиля одну строку:

> Музыку сначала ищи в Spotify (spotify_play).

Тогда YouTube остаётся запасным вариантом: когда Spotify ничего не нашёл или просят видео.

## Известные ограничения

- Пауза на время разговора опирается на строки журнала YaJarvis. Если обновление ядра изменит их текст, плагин не увидит конец разговора; тогда через 3 минуты сработает страховка и музыка продолжится сама.
- Карточки плеера в панели нет: плагин не может рисовать свой интерфейс.
- Только arm64.
- В некоторых версиях YaJarvis фразы про музыку уходят Алисе, когда включён канал умного дома «Алиса». Если у вас установлен мост Алисы со Spotify, это может запустить второй, другой трек. Обходной путь: выключить этот канал или не обращать внимания.
- Строка статуса в карточке плагина не показывается. Спросите голосом «что играет в Spotify».

## Сборка из исходников

```sh
cargo test
scripts/release.sh
```

Для `scripts/release.sh` нужен rustup с целью `aarch64-unknown-linux-musl` и zig (для C-зависимостей). Скрипт соберёт `dist/jarvis-plugin-arm64.zip`.
